## 摘要
当多模态人工智能智能体被要求遗忘某个事实时，当前的记忆系统通常会删除文本条目并报告成功。我们发现，该事实仍可从保留的用户图像中恢复，包括标记为完全不同事实的图像，因为视觉语言模型（VLM）在推理时使用了隐式的视觉线索。我们引入了信息溯源图（IPG），这是一种按删除可能性对记忆表示进行分类的分类体系。IPG揭示了删除失败的多条途径。我们的基准测试MemLeak在删除级联中测量了这一点：直接探测支持删除的系统得到的成功率<1%，但保留的相关文本使得18.3%的事实可恢复，保留的图像使得12.0%可恢复（盲基线为0.0%，误检率为0.3%）——其中47%的图像泄漏无法通过文本恢复。内容感知的语义删除将图像残留降至2.0%。这种残留出现在多个VLM、一个生产记忆系统以及真实Unsplash授权照片中。双标注人员的人类验证（kappa = 0.88）确认了评判的可靠性。

## Abstract
When a multimodal AI agent is asked to forget a fact, current memory systems usually delete the text entry and report success. We find that the fact can remain recoverable from retained user images, including images tagged to entirely different facts, because VLMs use implicit visual cues at inference time. We introduce the Information Provenance Graph (IPG), a taxonomy that classifies memory representations by deletion affordance. The IPG reveals that deletion fails through multiple channels. Our benchmark, MemLeak, measures this across a deletion cascade: direct probing of deletion-capable systems yields <1%, but retained correlated text enables 18.3% recovery, and retained images enable 12.0% recovery (0.0% blind baseline, 0.3% FPR) -- with 47% of image leaks not text-recoverable. Content-aware semantic deletion reduces the image residual to 2.0%. The residual appears across multiple VLMs, a production memory system, and real Unsplash-licensed photographs. Dual-annotator human validation (kappa = 0.88) confirms judge reliability.

# MemLeak：诊断多模态智能体记忆中的信息泄漏 —— 论文详细总结

## 1. 核心问题与整体含义

- **研究动机**：多模态 AI 智能体（如个性化助手）在被要求“遗忘”某个事实时，当前记忆系统通常只删除文本条目并报告成功。然而，事实仍可能从保留的用户图像中恢复——包括标记为不同事实的图像。原因是视觉语言模型（VLM）在推理时会利用图像中的隐式视觉线索（如地理标志、文化背景、物体关联），从而“拼凑”出已删除的事实。
- **整体含义**：这构成一种“信息泄漏”漏洞，违反数据保护法规（如 GDPR 第 17 条“被遗忘权”）的精神，且现有审计机制无法检测（图像通道完全透明）。论文揭示了多模态记忆系统中删除操作的根本性不足——不仅仅是工程缺陷，更是由视觉模态的分布式隐式表示导致的架构性困难。
- **核心问题**：多模态智能体记忆中的事实级删除能否真正实现？如果不能，泄漏的通道、规模和对抗方法是什么？

## 2. 方法论

### 2.1 核心思想：信息溯源图（IPG）

- **定义**：IPG 是一个有向无环图 \( G_f = (V_f, E_f, \delta) \)，其中：
  - \( V_f \) 是事实 \( f \) 在所有存储层的不同表示节点（文本条目、文本嵌入、图像文件、图像嵌入、图边、隐式视觉特征、派生事实、行为模式等）。
  - \( E_f \) 是信息流边（表示派生关系）。
  - \( \delta : V_f \to \{addr, link, unreach\} \) 是删除可能性：
    - **addressable（可寻址）**：系统能根据事实 ID 直接定位并删除。
    - **linked（已链接）**：只有通过溯源链接才能删除（通常未建立）。
    - **unreach（持久）**：当前存储级删除机制无法触及（如隐式视觉特征）。
- **遗忘完备性**：\( FC_S(f) = \frac{|\{v \in V_f: v \text{ 被 S 删除}\}|}{|V_f|} \)，衡量删除比例。
- **泄漏 vs. 通用推理**：仅当系统使用**同一用户的保留数据**重建已删除事实时才认定为泄漏（排除模型通用知识）。

### 2.2 关键技术细节

- **删除级联**：评估三条泄漏通道：
  1. **直接探测**：向系统直接提问已删除事实（<1%）。
  2. **文本通道**：保留的相关文本通过 LLM 推理恢复（18.3%）。
  3. **图像通道**：保留的图像通过 VLM 推理恢复（12.0%）。
- **内容感知语义删除**：删除后，用 VLM 审计员扫描剩余图像，若与删除事实语义相关则标记删除。将图像泄漏从 12.0% 降至 2.0%（代价：移除 21.0% 的保留图像）。
- **对抗基线**：盲目推理（无上下文）0.0%，负对照（其他用户图像）0.3%。

### 2.3 探头类型

| 探头 | 目标 IPG 层 | 说明 |
|------|-------------|------|
| P1 | link (文本删除，图像探测) | 删除事实文本，用保留图像询问 VLM |
| P2 | link (反向) | 删除事实图像，用文本查询 |
| P3 | unreach (持久) | 事实从未存储为文本，仅存在于图像中 |
| P4 | derived | 从 2-3 张保留图像联合重建 |
| P5 | unreach (行为) | 行为模式在删除后仍存在 |

## 3. 实验设计

### 3.1 数据集

- **合成档案**：113 个实体档案，每个包含 20 个事实（10 个删除目标 + 10 个保留），涵盖 5 个类别（位置、职业、偏好、关系、所有物）。事实分为显式视觉、隐式视觉和纯文本三种视觉基础。
- **规模**：
  - 纯文本子集：113 个档案，2260 个事实，1053 次探测。
  - 多模态子集：38 个档案，760 个事实，536 张生成图像，300 次探测。
  - 试点子集：5 个档案，100 个事实，115 张图像，55 次探测（用于策略消融）。
- **真实图像**：523 张 Unsplash 照片（CC 许可）用于同一 38 个档案，验证生态有效性。

### 3.2 评估系统

| 系统 | 描述 |
|------|------|
| Long-context | 无删除，仅行为抑制 |
| Naive | 仅删除文本，保留全部图像 |
| Mem0 | 生产级 RAG 系统，语义搜索删除文本，不处理图像 |
| Letta | 模拟的智能体管理记忆，仅删除 LLM 能表述的文本 |
| Oracle | 完美溯源删除：删除文本、嵌入、图像、图边 |

另外测试了不同 VLM（Claude Sonnet 4, GPT-4o）作为探测器，以及 3 模型评判集成（GPT-4.1, Claude Sonnet 4, Gemini 2.5 Flash）。

### 3.3 基准（Benchmark）

- **MemLeak**：包含上述数据集、探头定义、评估管道和指标（跨模态泄漏率 CMLR，95% Wilson 置信区间）。
- **评判**：3 模型 LLM 集成进行多数投票，Cohen's κ = 0.73-0.91。人工验证（2 名标注者，100 个样本）κ = 0.88。

## 6. 主要结论与发现

1. **直接探测无效**：所有支持删除的系统对直接提问的泄漏率 <1%（n=1053）。
2. **文本通道泄漏显著**：保留的相关文本使 18.3% 的已删除事实可恢复。
3. **图像通道泄漏独特且严重**：保留图像（标记到其他事实）使 12.0% 事实可恢复；且 47% 的图像泄漏无法通过文本恢复（意味着文本审计完全无法检测）。
4. **语义删除有效但非完全消除**：内容感知的 VLM 审计将图像残留从 12.0% 降至 2.0%（代价：移除 21% 的保留图像）。
5. **生产和真实环境均复现**：Mem0 端到端泄漏 16.3%；真实 Unsplash 照片泄漏 10.6%（与合成数据 12.0% 重叠）。
6. **跨模型稳健**：Claude Sonnet 4 和 GPT-4o 泄漏率相近（12.0% vs 9.3%），但部分泄漏不同，暗示联合多模型审计更有效。
7. **人机一致性高**：双标注者 κ=0.88，集成与人类 κ=0.84，验证评判可靠性。

## 8. 不足与局限

- **数据以合成为主**：主要实验使用 GPT 生成画像和 Gemini 生成图像，缺乏真实用户照片集合（虽然 Unsplash 验证了视觉真实性，但用户照片的交叉事实关联模式可能不同）。
- **生态效度有限**：真实照片仍是库存图片，非实际用户上传的带有多重上下文的数据，可能低估或高估实际部署中的泄漏。
- **Letta 模拟**：未使用完整 Letta 服务器，仅模拟核心行为，可能与真实系统有差距。
- **评判短板**：3 模型集成在共识一致时与人类高一致，但分裂票（1/3）时仅 37.5% 与人类一致，意味着可能漏检或误检一部分泄漏（论文承认并建议特殊处理分裂票）。
- **Mem0 端到端结果混合多个失败模式**：无法完全分离文本残留和图像通道贡献，只能作为系统级测量。
- **IPG 是描述性而非预测性**：不能预先计算不同系统能实现怎样的遗忘完备性，需实际测量。
- **语义删除代价未深入探讨**：移除 21% 的保留图像对下游性能（如保留事实回忆）的影响未量化。
- **2.0% 残留的根源不明**：论文推测需要表示级干预（隐私感知编码器、嵌入擦除），但未进行实证解决。
