## 摘要
图像生成模型在海量、大多未经过严格筛选的互联网规模数据集上训练，这些数据中包含不期望的视觉概念。在保持输出图像质量不降低的前提下，高效地从模型生成中移除这些概念仍然具有挑战性。我们提出了一种新颖的概念移除方法，适用于前沿扩散模型和图像自回归模型，如SD3.5、Flux和Infinity。我们的干预措施是将所有这些现代模型中存在的内部瓶颈层替换为一个转码器，该转码器经过训练以复制原始层，同时将其结构化为不同的激活特征。这种原地替换创建了一个集成的过滤器，通过该过滤器可以有选择地禁用特定于概念的信号，同时保持模型其余部分的行为。由于该干预措施修改了模型主干而非附加外部组件，因此在白盒访问下它保持持久性。实验上，该方法在现代扩散模型和自回归模型上实现了最先进的概念移除性能，保持了视觉生成质量，提供了对抗对抗性提示的鲁棒性，并支持顺序移除多种概念。这使我们的方法成为前沿图像生成模型中概念移除的一种实用方法。

## Abstract
Image generative models are trained on massive, largely uncurated internet-scale datasets that contain undesirable visual concepts. Efficiently removing such concepts from the model generations without degrading the quality of output images remains challenging. We introduce a novel concept removal method for frontier diffusion and image autoregressive models, such as SD3.5, Flux, and Infinity. Our intervention replaces the internal bottleneck layer present in all these modern models with a transcoder that is trained to replicate the original layer while structuring it into distinct activation features. This in-place substitution creates an integrated filter through which concept-specific signals can be selectively disabled while preserving the rest of the model's behavior. Since the intervention modifies the model backbone rather than attaching an external component, it remains persistent under white-box access. Empirically, the approach achieves state-of-the-art concept removal performance across modern diffusion and autoregressive models, maintains visual generation quality, provides robustness against adversarial prompts, and supports sequential removal of diverse concepts. This positions our method as a practical approach for concept removal in frontier image generative models.

## 1. 核心问题与研究动机

图像生成模型（如扩散模型、图像自回归模型）在互联网规模的未筛选数据集上训练，不可避免地学习到不期望的视觉概念（如侵权艺术风格、不当物体、NSFW内容）。现有概念移除方法存在两难：

- **外部方法**（如SAE-based、推理时干预）不修改模型主干，容易被白盒移除或绕过，不持久。
- **内部方法**（如训练/微调、闭式权重编辑）虽修改权重，但训练成本高、依赖特定架构、顺序移除时累积误差导致质量下降。

**本文目标**：提出一种**持久、高效、通用**的概念移除方法，适用于前沿视觉生成模型（SD3.5、Flux、Infinity），在不损害生成质量的前提下实现单概念与多概念移除，并抵抗对抗性提示。

## 2. 方法论：BLOCK（Bottleneck-Layer-Oriented-Concept-Knockout）

### 核心思想
前沿模型中存在一个**架构决定的瓶颈层**——文本编码器与生成主干之间的变换层（如投影层、MLP）。BLOCK **将此瓶颈层原地替换为一个训练好的 transcoder**，该 transcoder 复制原始功能但将其激活特征组织为**单语义（monosemantic）特征**。通过识别与目标概念相关的特征并重新定向其解码器贡献，实现概念抑制。

### 关键技术细节

1. **Transcoder 结构**：
   - 编码器：`z = TopK(W_enc x + b_enc)`
   - 解码器：`y_hat = W_dec z + b_dec`
   - 使用 **TopK 激活函数**实现硬 ℓ₀ 约束（保留 k 个最大非零元素），替代原 ReLU 的 ℓ₁ 收缩，获得更清晰的特征分离。

2. **训练损失**（组合损失，公式4）：
   - **保真度损失**：`L_fidelity = ∥y - y_hat∥₂² / Var(y)`，迫使 transcoder 复现原始层输出。
   - **多 TopK 损失**：`L_multi-topK`，用更大的 k（4k）重建输出，促进渐进代码利用率。
   - **辅助损失**：`L_aux`，仅使用死神经元（连续不激活）重建，缓解死亡单元问题。
   - 所有分量按目标方差归一化，代表未解释方差比例。

3. **概念移除干预**：
   - 对目标概念 t 的每个 token，记活跃 latent 集合 A_t。同时获取空 token ∅ 的活跃 latent 集合 A_∅。
   - 建立双射 π: A_t → A_∅（默认按序配对）。
   - 修改解码器 W_dec：将 A_t 对应的列替换为 A_∅ 对应列（按 π 映射），并缩放确保数值稳定性。
   - 结果：目标概念的贡献被重定向为空 token 的输出，从而移除概念。

4. **持久性**：transcoder 直接嵌入模型主干，**不是可分离的外部模块**，白盒访问也无法绕过。

## 3. 实验设计

### 数据集与基准
- **UnlearnCanvas**：原始风格分类器基于 SD1.5，对现代模型（SD3.5、Flux、Infinity）准确率<6%，故替换为 **LLaVA-1.6-Vicuna-7B** 零样本分类器。
- 选择 **10 种艺术风格**（Van Gogh、Picasso、Cartoon、Cubism 等）和 **20 个物体类别**（来自 UnlearnCanvas）。
- 额外使用 **I2P 基准**（NSFW 检测）、**P4D 基准**（红队攻击）、**Ring-A-Bell/MMA-Diffusion/UnlearnDiff** 对抗攻击。

### 对比方法
- **主要基线**：UCE（闭式权重编辑）、LOCOEDIT（局部闭式编辑，对 SD3.5/Flux 适配为零消融定位）
- **额外基线**（部分模型）：EraseAnything、SAeUron、AGE、ConceptPrune、GLoCE、AdaVD、SafetyGap

### 评估指标
- **UA**（Unlearning Accuracy）：含目标概念的 prompt 生成图像不被分类为目标的比例。
- **IRA**（In-domain Retain Accuracy）：同一领域（如其他风格）非目标概念分类准确率。
- **CRA**（Cross-domain Retain Accuracy）：跨领域（如物体 vs 风格）保留能力。
- **FID、CLIP Score、HPSv3、Aesthetic v2.5**：图像质量。

### 实验设置
- 训练 transcoder 使用 17,600 条 prompt（80 per object × 20 objects × 11 style variant），MLP 层额外使用 30,000 条 MS-COCO prompt + style 增强。
- TopK k=32，扩展因子 16，训练 100 epoch。

## 6. 主要结论

- **概念移除性能 SOTA**：BLOCK 在所有四种模型上的 UA、IRA、CRA 均显著优于 UCE 和 LOCOEDIT（例如 Flux 风格 UA 88.6% vs 66.45%/67.43%）。
- **保持生成质量**：FID、HPSv3、Aesthetic 分数接近未编辑模型，优于基线。
- **多概念移除鲁棒**：顺序或同时移除可达 N=10，性能仅缓慢下降，而基线急剧劣化。
- **对抗鲁棒性**：Ring-A-Bell 攻击成功率降低 33–36 个百分；MMA/UnlearnDiff 攻击也最低。
- **通用性**：同时适用于扩散模型（SD3.5、Flux）和自回归模型（Infinity-2B/8B），无需为不同架构修改框架。
- **持久性**：干预嵌入主干，无法被外部移除或绕过。

## 7. 优点

1. **永久且不可绕过**：直接修改模型主干，拒绝服务型外部安全模块的缺陷。
2. **训练轻量**：仅训练轻量 transcoder，无全模型反向传播，前置成本可接受且一次支付。
3. **多概念扩展性优异**：顺序移除不累积误差，且支持同时移除。
4. **对抗鲁棒性强**：在多种攻击基准上均优于现有方法。
5. **架构无关**：可应用于不同训练范式（扩散/自回归）和不同规模（2B–12B）。
6. **保持图像质量**：性能提升的同时不牺牲 FID、美学评分等质量指标。

## 8. 不足与局限

1. **一次性训练成本**：每个新模型部署需重新训练 transcoder（10–100分钟），虽不高但对频繁迭代不友好。
2. **概念覆盖有限**：仅验证风格和物体两类概念，未评估其他类型（如动作、情感、NSFW 仅少量测试）。
3. **分类器偏差**：使用 LLaVA 替代 UnlearnCanvas 原始分类器，虽经人工对齐（94.4%匹配率），但仍可能带来偏差。
4. **攻击并非完全消除**：对抗攻击成功率虽大幅降低但未归零，鲁棒性仍有提升空间。
5. **模型选择**：仅测试四种模型（SD3.5、Flux、Infinity-2B/8B），未覆盖更早的 U-Net 架构或其他 IAR 模型（如 HART），通用性边界有限。
6. **未探讨概念重新引入风险**：未分析是否可能通过精心设计的输入恢复被移除概念（除简单 prompt 外）。
