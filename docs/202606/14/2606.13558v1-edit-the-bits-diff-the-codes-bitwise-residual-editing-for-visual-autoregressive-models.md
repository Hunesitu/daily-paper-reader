## 摘要
基于文本引导的图像编辑与视觉自回归（VAR）生成器需要控制模型采样的内容以及将采样变化写回图像编码的位置。现有的VAR编辑器主要操作令牌流、特征或平铺的下一个令牌对数几率，未充分利用逐位残差VAR模型的两个原生结构：每位的伯努利预测头和构建图像的多尺度残差编码场。我们提出了BitResEdit，一种针对逐位残差VAR生成器（如Infinity）的无训练编辑器。BitEdit通过沿共享编辑前缀上的源-目标对比倾斜后CFG的逐位对数几率来实现源负向引导，然后将每个更新投影到干净CFG采样器周围的闭式伯努利-KL信任区域内。ResEdit将采样的位转换为逐尺度连续编码残差，用局部化掩码门控这些残差，并通过生成器原生的尺度求和重新注入。它们共同将决策时的位引导与组合时的编码组合相结合，从而通过编码算术精确保留被掩码的潜在特征，同时在目标区域内应用局部化、尺度感知的编辑。在PIE-Bench上使用Infinity-2B，BitResEdit在相同骨干网的VAR编辑器中实现了最强的文本对齐，编辑区域上的CLIP比最强先前的编辑器提高了+1.07，同时背景保持与之一致。消融实验表明，BitEdit和ResEdit在目标对齐和背景保持中扮演互补角色。

## Abstract
Text-guided image editing with visual autoregressive (VAR) generators requires controlling both what the model samples and where the sampled change is written back into the image code. Existing VAR editors mainly operate on token streams, features, or flat next-token logits, leaving two native structures of bitwise-residual VAR models underused: the per-bit Bernoulli prediction head and the additive multi-scale residual code field from which the image is assembled. We propose BitResEdit, a training-free editor for bitwise-residual VAR generators such as Infinity. BitEdit performs source-negative guidance by tilting the post-CFG per-bit log-odds along a source--target contrast computed on a shared edited prefix, then projects each update into a closed-form Bernoulli-KL trust region around the clean CFG sampler. ResEdit converts the sampled bits into per-scale continuous-code residuals, gates them with a localization mask, and re-injects them through the generator's native sum-of-scales. Together they couple decision-time bit guidance with combination-time code composition, so masked-out latent features are preserved exactly by code arithmetic while localized, scale-aware edits are applied inside the target region. On PIE-Bench with Infinity-2B, BitResEdit attains the strongest text alignment among same-backbone VAR editors, improving CLIP on the edited region by +1.07 over the strongest prior editor while keeping background preservation competitive with it. Ablations show BitEdit and ResEdit play complementary roles in target alignment and background preservation.

## 2. 方法论：核心思想、关键技术细节

### 核心思想
BitResEdit分为两步：
- **BitEdit**：在采样前，通过源-目标对比方向倾斜后CFG的每比特对数几率，并投影到伯努利-KL信任区域内，以保持与目标条件生成器的行为接近。
- **ResEdit**：在采样后，将采样的比特转换为连续编码残差，通过定位掩码门控，然后通过Infinity原生的尺度求和重新注入累积潜在编码，被掩码位置残差为零，精确保留背景。

### 关键技术细节
1. **预备知识**：
   - Infinity使用多尺度残差生成：最终VAE编码 z = Σ_up(ck)，其中ck来自二进制球面量化器（BSQ），每个比特b∈{-1,+1}^D，连续码 c = b/√D。
   - 每尺度的预测头输出每比特的先验对数几率 dk(y)，条件于文本y和先前尺度。分类器自由引导（CFG）在线性空间进行。

2. **BitEdit**（决策时，在对数几率空间）：
    - 在每个尺度k，进行一次三分支前向传播：目标(T)、无条件(∅)、源(S)，得到对应的对数几率d(T), d(∅), d(S)。
    - 计算源-目标对比：Δk = d(S) - d(T)。
    - 计算原始引导对数几率（温度τ）：d_raw = (d_cfg - ηk * Mk * Δk) / τ，其中ηk是逐尺度强度（线性退火），Mk是空间-比特掩码（仅编辑区域）。
    - **伯努利-KL信任区域投影**：将d_raw投影到以干净CFG采样器d_cfg/τ为中心的KL球（半径δ）内，得到d_guided。通过二分法求解混合权重λ，使得KL(Bern(σ(λ d_raw+(1-λ) anchor)) || Bern(σ(anchor))) ≤ δ。附加L∞安全性钳位。
    - 采样得到二进制令牌（使用顶级/顶部-p截断）。

3. **ResEdit**（组合时，在编码空间）：
    - 使用BSQ将采样比特转换为连续码ck，上采样到最终VAE分辨率，与缓存源编码ck_src形成残差Δck = ck - ck_src。
    - 定位掩码处理：二值掩码经膨胀、双线性resize、高斯模糊、峰值归一化得到软门控Gfinal。
    - 输出编码 = ck_src + α * Gfinal ⊙ Δck。
    - 累积潜在编码 z = Σ_out，最终解码为图像。

4. **耦合**：BitEdit和ResEdit通过共享的编辑前缀（来自上一步的累积潜在）耦合。ResEdit的输出作为下一尺度的视觉前缀（连续非原生令牌流）。

## 3. 实验设计

### 数据集与基准
- **PIE-Bench**：标准文本引导图像编辑基准，包含700个源-目标对，覆盖10个编辑类别（随机、改变/添加/删除对象、属性变化、改变背景、改变风格等）。

### 对比方法
- **扩散模型**：P2P, MasaCtrl, P2P-Zero, NTI, PnP-Inv, NP, StableFlow, RF-Edit, FlowEdit, VAGS, FlowChef, RewardFlow。
- **视觉自回归模型**：AREdit, MLN, VAREdit-8B, EditInfinity。
- 所有方法基于相同骨干（Infinity-2B）或各自官方实现。

### 度量指标
- **背景保持**：PSNR↑, LPIPS↓, MSE↓, SSIM↑。
- **文本对齐**：CLIP整图相似度（Whole）和编辑区域相似度（Edited）。

### 实现细节
- 使用Infinity-2B（13尺度，32位BSQ），文本编码器Flan-T5-XL。
- BitResEdit超参数：CFG尺度s=5，η0=3线性退火，δKL=1.0，τ=1.0，top-k=900，top-p=0.97，α=1.0。
- 默认使用PIE-Bench提供的真实掩码，也测试了自动GroundingDINO+SAM掩码和紧密边界框。

## 6. 主要结论与发现

1. **BitResEdit在Infinity-2B上达到最强文本对齐**：
    - CLIP编辑区域得分比最强先前同骨干编辑器EditInfinity高 **+1.07**（24.54 vs 23.47）。

## 7. 优点

1. **无训练**：完全无需微调或优化，直接基于冻结的Infinity生成器，即插即用。
2. **原生结构利用**：明确利用逐位伯努利预测头和加法残差码场，而非黑盒令牌重排。

6. **实验充分**：详尽的消融、类别分析、掩码鲁棒性测试，代码开源。
7. **强可迁移性**：方法适用于任何逐位残差VAR生成器（如Infinity），不依赖特定架构。

## 8. 不足与局限

1. **依赖用户提供掩码**：BitResEdit需要一个二值定位掩码，掩码质量直接影响编辑结果。实验显示，弱掩码（如松散边界框）会严重破坏背景保持；自动GroundingDINO+SAM掩码虽接近GT，但仍存缺陷（遗漏、幻觉等）。这限制了在无可靠掩码场景下的应用。

2. **对象删除表现差**：在需要去除对象时，由于目标提示不指定填充内容，模型会生成不理想的填充（重样式、伪影、全图重绘），导致编辑区域CLIP得分极低（19.4）。这本质上是减法编辑与生成先验不匹配的问题。

3. **度量偏差**：CLIP编辑区域得分在删除任务中可能被低估，因为成功的删除应将区域变为背景，背景缺乏正面对齐的文本，因此CLIP得分天然低，部分低估真实质量。

4. **PSNR相对较低**：虽然背景保持整体竞争力，但PSNR是BitResEdit最弱的指标（26.67），落后于EditInfinity（27.95）和MLN（29.70）。作者指出这是保留对齐取向的权衡。

5. **仅针对Infinity验证**：虽然声称适用于任意逐位残差VAR模型，但实验仅在Infinity-2B上进行，对其他变体（如VAR、FlexVAR）的泛化性未测试。

6. **掩码精度的应用限制**：实际部署需依赖外部定位流水线（如GroundingDINO+SAM），这引入了额外的不确定性和延迟。
