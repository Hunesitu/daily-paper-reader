## 摘要
视觉自回归（AR）模型通过预测由视觉分词器解码的离散令牌来生成图像。尽管展现出强大的整体图像生成能力，但在文本渲染方面仍表现不佳，存在笔画模糊、破坏字母形状等问题。在本文中，我们将这一局限性追溯到视觉分词器——它难以重建精细细节。改进分词器虽直接但成本高昂，因为需要重新训练分词器和AR模型。我们能否在不重新训练现有分词器和AR模型的情况下提升AR模型的文本渲染性能？为实现这一目标，我们提出了残差解码器适配器（RDA），它在不改变分词器令牌空间的前提下，事后升级现有分词器。具体而言，它通过引入两个新型组件来改进视觉分词器的解码器输出：（i）一个与原始分词器共享令牌分布的配对码本；（ii）一个并行分支，用于学习像素空间中重建图像与真实图像之间的微小差异（残差）。这种残差设计使我们能够非侵入式地增强分词器，同时保持与先前AR模型的兼容性。RDA显著提升了文本渲染性能。例如，在竞争性的TextAtlas基准上，我们将微调后的Janus-Pro OCR准确率从24.52%提升至58.26%（TextVisionBlend），从12.75%提升至36.81%（StyledTextSynth）。代码已开源：https://github.com/CSU-JPG/RDA

## Abstract
Visual Autoregressive (AR) models generate images by predicting discrete tokens that are decoded by a visual tokenizer. Despite demonstrating strong overall image generation ability, they still underperform on text rendering with blur strokes and disrupt letter shapes. In this work, we trace this limitation to the visual tokenizer, which struggles to reconstruct fine-grained detail. Improving the tokenizer is straightforward but expensive, as it necessitates retraining both the tokenizer and the AR model. Can we improve text rendering performance of AR models without retraining the existing tokenizer and AR model? To achieve this, we propose the Residual Decoder Adapter(RDA) that upgrades an existing tokenizer post-hoc without changing its token space. Specifically, it refines the decoder output of the visual tokenizer by introducing two novel components: (i) a paired codebook that shares the token distribution with the original one; (ii) a parallel branch to learn the tiny differences (residual) between the reconstructed image and the ground-truth images in the pixel space. This residual design allows us to enhance the tokenizer non-invasively while preserving compatibility with prior AR models. RDA substantially improves text rendering significantly by a large margin. For instance, we boost finetuned Janus-Pro OCR accuracy rises from 24.52% to 58.26% (TextVisionBlend), from 12.75% to 36.81% (StyledTextSynth) on competitive TextAtlas benchmark. The code is available at https://github.com/CSU-JPG/RDA

## 1. 论文的核心问题与整体含义（研究动机和背景）

视觉自回归（AR）模型在图像生成上表现强劲，但在文本渲染任务中严重落后于扩散模型，输出文字常出现笔画模糊、字形扭曲等问题。论文将这一瓶颈追溯到视觉分词器：其量化‑解码过程会丢失细粒度高频细节，且由于AR模型完全依赖离散令牌重建，一旦信息在量化阶段丢失，后续生成无法恢复。直接改进分词器（如扩大码本、引入新目标）会改变令牌分布，迫使整个AR模型重新训练，成本极高。因此，论文的核心目标是：**在不重新训练现有分词器和AR模型的前提下，提升AR模型的文本渲染质量。**

## 2. 论文提出的方法论：核心思想、关键技术细节

**核心思想**：保持原始分词器冻结，在解码器后附加一个轻量级残差学习模块，预测原始重建图像与真实图像之间的像素级差异，从而弥补量化丢失的细节。该方法不改变令牌空间，因此原AR模型无需任何微调即可直接受益。

**关键技术细节**：

- **共享ID提示码本（Shared‑ID Hint Codebook）**：在原始码本旁增加一个可训练的新码本，两个码本使用**相同的令牌索引**。对于同一个索引，原始码本提供全局语义特征，新码本提供互补的高频细节特征。这种共享ID设计保证了新码本不会改变令牌分布，AR模型可直接使用。
- **残差解码器（Residual Decoder）**：将原始码本特征和新码本特征分别通过投影器融合（简单相加），得到混合特征；然后一个并行的小型解码器（继承原解码器架构并加宽最后两层通道）从混合特征预测残差图像 `ΔÎ`。最终精炼图像为 `Î_final = Î + ΔÎ`。
- **训练目标**：包含多项损失函数：
  - 像素级损失（MAE + MSE）监督残差和最终重建；
  - 感知损失分别应用于最终图像和残差图像（关键，避免残差训练失败）；
  - Sobel边缘损失增强梯度区域约束；
  - 频率域损失（对残差做FFT后用高通掩模约束）。
- **训练流程**：冻结原始分词器，仅训练新码本、新投影器和残差解码器。推理时，AR模型生成令牌序列后，同时从两个码本查找特征，融合后经残差解码器得到精炼图像。

## 6. 论文的主要结论与发现

- RDA能**大幅提升**AR模型文本渲染质量。例如，微调后的Janus‑Pro 1B在StyledTextVisionBlend上OCR准确率从24.52%提升至58.26%（+33.74点）。
- RDA的增益在**文本专用模型**上尤其显著，因为此时tokenizer重建成为主要瓶颈；而在通用模型上提升较小（+1~2点），表明通用模型面临“令牌预测 + 重建”双重瓶颈。
- RDA对**不同AR架构和模型规模**均有效，且训练于256px后可直接泛化到384/512/1024px。
- RDA在**重建任务**上一致优于原始分词器（OCR准确率提升约10点），且优于需重新训练AR模型的TA‑Tok（数据效率高）。
- RDA的**OOD泛化能力**优于直接微调解码器（后者在ImageNet上FID飙升+5.12），因为RDA冻结了基础解码器，仅学习加性残差。

## 7. 优点

1. **非侵入式、兼容性好**：不改变令牌空间，无需重新训练任何AR模型，即插即用。
2. **数据高效**：仅用5M图像训练即可显著提升，而其他改进分词器的方法需1.28B图像。
3. **计算开销低**：推理时引入极少量参数和延迟（<2%）。
4. **跨架构、跨分辨率泛化**：单次训练即可适配多种AR模型和不同输出分辨率。
5. **设计巧妙**：共享ID码本 + 残差解码的结合，既保留了原有分布，又补偿了高频细节；残差感知损失和边缘损失有效解决了稀疏残差信号的优化困难。

## 8. 不足与局限

1. **无法纠正AR模型产生的错误令牌**：当AR模型生成结构错误的字符（如少笔画、错字）时，RDA仅在像素层面修复，无法改善语义级错误。
2. **极小/模糊字符场景受限**：若tokenizer已分配错误的令牌（如将极小字符量化为背景），残差解码器无法恢复，因为输入特征已丢失该信息。
3. **训练数据偏向**：RDA仅在5M Mario‑10M（文本丰富但场景有限）上训练，未在其他多样化文本数据集验证，可能对特定场景（如手写体、艺术字）泛化不足。
4. **未与其他后处理增强方法对比**：如基于超分的后处理或GAN修复，缺少此类直接比较。
5. **无法完全解决quantization loss**：残差学习仍受限于原码本的量化能力，当量化误差过大时改进幅度有限。
6. **对AR模型生成质量的上限依赖**：若AR模型本身文本预测能力极差，RDA效果有限（如通用模型提升较小）。
