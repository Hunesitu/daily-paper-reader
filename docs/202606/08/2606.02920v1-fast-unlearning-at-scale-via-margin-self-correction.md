## 摘要
语言模型遗忘学习更新一个预训练模型，使其表现得好像从未见过选定的训练样本，同时保留效用并避免昂贵的重新训练。现有方法通常使用固定的训练预算对预训练模型进行微调，然后通过在下游验证数据上评估多个保存的检查点来选择最终模型。两个不必要的计算来源限制了可扩展性：训练超出了理想遗忘-保留权衡的边界，以及需要额外存储和重复评估的检查点选择。为了解决这些限制，我们引入了边界自校正（MASC），一种高效的遗忘学习方法，具有不需要下游评估的在线停止规则。给定一个要遗忘的文本序列，MASC主动减少原始下一个token与最可能备选token之间的logit差距。一旦这个差距在所有遗忘序列中足够大比例的token位置上平均较小，MASC就会输出最终模型。在TOFU、MUSE News和MUSE Books上，MASC以现有基线计算成本的一小部分实现了具有竞争力的遗忘-保留权衡。我们进一步观察到，随着模型规模（即参数数量）的增加，MASC和SimNPO的权衡都得到改善——遗忘指标保持可比，而保留效用增加。

## Abstract
Language-model unlearning updates a trained model to behave as if it had not seen selected training examples, while preserving utility and avoiding costly retraining. Existing approaches typically fine-tune the pretrained model with a fixed training budget and select the final model afterwards by evaluating several saved checkpoints on downstream validation data. Two sources of unnecessary computation limit scalability: training beyond the desired forget-retain trade-off, and checkpoint selection that requires extra storage and repeated evaluations. To address these limitations, we introduce MArgin Self-Correction (MASC), an efficient unlearning method with an online stopping rule that does not require downstream evaluation. Given a text sequence to be forgotten, MASC actively reduces the logit gap between the original next token and the most likely alternatives. It outputs a final model once this gap is small on average over a sufficiently large proportion of token positions across all forget sequences. On TOFU, MUSE News, and MUSE Books, MASC achieves a competitive forget-retain trade-off at a fraction of the computational cost of existing baselines. We further observe that as we increase model size (a.k.a. number of parameters), the trade-offs improve for both MASC and SimNPO -- the forget metrics remain comparable while retain utility increases.

*   **整体含义**：论文旨在解决现有LLM遗忘方法效率低下的问题，提出一种能够自动停止的、成本更低的遗忘方法。

#### 2. 方法论：MArgin Self-Correction (MASC)

*   **核心思想**：MASC 的核心是“边际自校正”。它基于一个简单的观察：一个语言模型要*精确地*复现一个被遗忘的序列，需要在许多token位置上，当给定真实前缀时，对该目标token赋予极高的概率。MASC 的目标是主动降低这种支配性，使得目标token不再明显优于其最可能的备选token。

*   **关键技术细节**：
    1.  **限制性概率与边际 (Restricted Margin)**：对于遗忘序列中的每个token位置，MASC 计算一个“限制性边际” `m`。这个边际衡量了目标token的logit与模型自身提出的前k个最可能备选token的logit的log-sum-exp聚合值之间的差距。`m` 值越大，表示模型仍然强烈倾向于原始token。
    2.  **遗忘条件**：当 `m` 小于某个阈值 `τω` 时，认为该token已被“局部抑制”。MASC 的优化目标是使遗忘集中超过一定比例 (`1 - α`) 的token位置都满足这个条件。
    3.  **目标函数**：MASC 通过优化一个包含两项的拉格朗日目标函数来解决这个问题：
        *   **保留项**：最小化模型在保留数据上的KL散度，以防止模型遗忘非目标知识。
        *   **遗忘项**：最小化一个“铰链损失”，该损失惩罚那些边际 `m` 大于阈值 `τω` 的token位置。
    4.  **在线停止规则 (Online Stopping Rule)**：这是MASC最关键的创新。它使用一个小的验证集 `Dval`（从遗忘集中随机抽取）来在线监测“违反率” `V_rho`。当 `V_rho` 首次降至预设的容忍度 `α` 以下时，训练立即停止，并输出当前的模型参数。这**完全不需要使用下游评估数据或事后检查点选择**。

*   **算法流程（文字说明）**：
    1.  从预训练模型 `πθ0` 初始化。
    2.  对于每个训练步骤，从遗忘集中采样一个批次 `Bfg`，从保留集中采样一个批次 `Bret`。
    3.  对 `Bfg` 中的每个token位置，计算其限制性边际 `m`。如果 `m` 高于活跃阈值，则计算其铰链损失 `ℓMASC`。
    4.  计算保留集的KL散度损失 `Lret`。
    5.  结合两项损失（`L = λfg * Lfg_loss + λret * Lret`）更新模型参数（通常使用LoRA）。
    6.  定期（每步或每几步）从遗忘集中抽取一个小的子集 `Pfg`，计算其平均违反率 `V_rho`。
    7.  如果 `V_rho ≤ α`，则停止训练，返回当前模型。否则，继续步骤2。
