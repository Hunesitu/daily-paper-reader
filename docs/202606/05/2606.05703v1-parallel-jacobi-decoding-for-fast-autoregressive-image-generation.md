## 摘要
自回归模型在生成高保真图像方面展现了卓越的性能。然而，其固有的顺序下一个令牌预测导致推理速度显著变慢。近期研究引入了雅可比风格解码以加速自回归图像生成。扩展草案序列最初能提高效率，但随着一维序列中的错误传播阻碍收敛，加速效果迅速饱和。观察到图像具有强烈的局部空间相关性，我们提出并行雅可比解码（PJD），一种无需训练的解码方法，将草案令牌扩展到二维空间域中，实现高效的空间并行细化。PJD调整注意力掩码以减轻错误累积并提高收敛稳定性。在多个数据集上的大量实验表明，PJD在多种自回归图像生成模型上实现了4.8倍至6.4倍的加速，同时保持了有竞争力的生成质量。

## Abstract
Autoregressive (AR) models have demonstrated remarkable performance in generating high-fidelity images. However, their inherently sequential next-token prediction leads to significantly slower inference. Recent studies have introduced Jacobi-style decoding to accelerate autoregressive image generation. Extending the draft sequence initially improves efficiency, yet the acceleration quickly saturates as error propagation in the one-dimensional sequence hinders convergence. Observing that images exhibit strong local spatial correlations, we propose Parallel Jacobi Decoding (PJD), a training-free decoding approach that expands draft tokens in the two-dimensional spatial domain to enable efficient spatially parallel refinement. PJD adjusts the attention mask to mitigate error accumulation and improve convergence stability. Extensive experiments on diverse datasets show that PJD achieves 4.8x-6.4x acceleration across multiple autoregressive image generation models while maintaining competitive generation quality.

## 1. 论文的核心问题与整体含义（研究动机和背景）
- **核心问题**：自回归图像生成模型（如 Lumina-mGPT、LlamaGen）依赖逐 token 的顺序下一令牌预测，导致推理过程极其缓慢（生成一幅 1024×1024 图像需数千步），严重制约其在实际应用中的部署。
- **研究背景**：近年来，加速自回归生成的方法包括推测解码（需额外草稿模型）和雅可比解码（无需训练但收敛后加速饱和）。现有的一维雅可比解码在图像生成中因误差沿一维序列传播而过早饱和，未能充分利用图像天然的二维空间局部性（注意力机制可视化显示每个 token 主要关注邻近区域）。

## 2. 论文提出的方法论：核心思想、关键技术细节
- **核心思想**：利用图像的空间局部性，将雅可比解码从一维扩展至二维空间域，在每轮迭代中并行启动多行的草稿 token 并进行联合优化，实现空间并行细化，从而大幅减少全局推理步数。
- **关键技术细节**：
  - **动态 Token 准备**：根据前一行已生成的 token 数量（Context Token Count）逐行激活新行。当上一行生成 token 数达到阈值 Tctx 时，新行开始参与解码，并初始化一段长度受限的草稿 token（最大长度 W）。初始化方式因模型而异（Lumina-mGPT 使用行结束符，LlamaGen 使用前一行末尾相似 token）。
  - **并行自回归预测**：一次前向传播中，利用“行因果注意力掩码”（Row-Causal Mask，RCM）计算所有活动行所有草稿 token 的条件概率。该掩码禁止当前行关注其他行的草稿 token，但允许访问已确认的前行 token，从而保持自回归依赖并避免跨行干扰。
  - **概率性 Token 验证**：采用随机接受准则，比较当前迭代与上一迭代中 token 的条件概率，若 u ≤ min(1, p_new / p_old) 则接受；否则拒绝。被拒绝的 token（仅针对最顶部活动行）从校准分布中重采样，保证每轮至少确认一个 token。这兼容随机采样（如 top-k sampling）。
- **算法流程**（文字描述）：初始化已确认 token 网格 → 每轮迭代：确定可激活新行 → 为每行追加草稿 token（长度动态） → 模型单次前向计算所有草稿概率 → 逐行从左到右验证，接受稳定 token，拒绝者重采样或保留为下一轮草稿 → 更新已确认网格 → 直到所有行生成完毕。
- **无训练**：所有过程无需额外模型训练或微调。

## 6. 论文的主要结论与发现
- **PJD 显著加速自回归图像生成**：在 Lumina-mGPT 上实现最高 **7.27 倍步数压缩**（c=9 时）、**6.96 倍延迟加速**；在 LlamaGen 上最高 **4.81 倍步数压缩**（c=6）。加速比随图像分辨率提高而增大（1024×1024 时达 6.9×）。
- **生成质量与 Vanilla AR 相当**：FID、CLIP-Score、IS 等指标均保持相近，甚至部分配置下优于 SJD 和 GSD。
- **鲁棒性**：在不同 top-k、CFG scale、分辨率下均保持稳定加速；注意力掩码（RCM）不可或缺，去除后步数和质量均下降。
- **优势根源**：二维并行策略使每步接受 token 数量远超一维雅可比解码，有效利用局部性，避免长距离误差传播。
